## One-command setup (Windows and Linux)

Install Python 3.10-3.13. From the cloned project root run:

~~~sh
python setup.py
~~~

This creates a local virtual environment, installs **requirements.txt**, downloads the versioned original CSV from GitHub, checks its SHA-256 and expected dimensions, and smoke-tests the notebook dependencies. If the GitHub release is unreachable, it falls back to the source Kaggle dataset, verifies the **same exact hash**, and refuses unexpected dataset versions.

Then run **python launch.py** and open the *unchanged* College_Majors_EDA_Colab.ipynb notebook.

## Manual installation

Download [college_majors_2026.csv from this GitHub Release](https://github.com/virat-kumar/college-majors-2026-earnings-debt-ml/releases/download/data-v1.0.0/college_majors_2026.csv), or obtain it from the [original Kaggle listing](https://www.kaggle.com/datasets/kylefengkfeng209/college-majors-2026-earnings-debt-jobs-ai). Place it **in the project root next to the notebook**. Running **python setup.py** then validates your existing copy rather than downloading again.

~~~text
college-majors-2026-earnings-debt-ml/
  College_Majors_EDA_Colab.ipynb  # original, unchanged
  college_majors_2026.csv         # downloaded automatically, ignored by Git
  split_ids.csv                   # generated by notebook, ignored by Git
  data/
    split_ids.csv                # tracked canonical reference snapshot
    README.md                    # attribution + exact checksums
    source_manifest.json         # generated local metadata, ignored by Git
~~~

**Important:** The original notebook writes a root-level split_ids.csv. This generated file remains ignored to prevent overwriting the tracked reference in **data/split_ids.csv**. Use the tracked reference for consistent group splits in further models.

The derived split CSV is shared under these same data-license terms; that license does not automatically apply to the team's notebook or code.

Rows represent public institution/program statistics rather than individual students. The notebook groups by institution identifier (opeid6) to avoid leakage across train/test or cross-validation folds. Outcomes are privacy-suppressed nonrandomly; report coverage and caveats. ## Troubleshooting

- **Python not recognized:** Install Python from https://python.org; on Linux use **python3 setup.py**, on Windows **py -3.13 setup.py** also works.
- **Missing venv / ensurepip on Ubuntu:** Install the matching python3-venv system package, then rerun setup.
- **Network unavailable:** Manually download the exact released CSV and place it next to the notebook.
- **SHA-256 or schema mismatch:** Verify the file version. Do not bypass checks to force incompatible data.
- **Notebook cannot find CSV:** Start Jupyter through **python launch.py** from the repository root; verify correct location.
- **Re-running the notebook rewrites split_ids.csv:** That is expected; the canonical reference is **data/split_ids.csv** and stays unchanged in Git.
- **Security:** Never commit Kaggle tokens, secret .env files, keys, arbitrary CSV output or virtual environments.
